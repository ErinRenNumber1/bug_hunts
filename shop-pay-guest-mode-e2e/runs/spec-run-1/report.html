Reading the result

What this run proves

  • The override header is honored from Erin's machine: treatment took effect on the first try, so Verdict trusted the request.
  • Under treatment a brand-new email lands in Pay checkout with no phone entry and no SMS code (frame at 9.0 s).
  • Address, card, Pay now and order confirmation all work end to end for the guest session.
  • The loop runs unattended in about 20 seconds, so more scenarios are cheap.

What it does not prove

  • Only the happy path. Bug-hunt cases 5 and 19 and the ten proposed edge cases are not yet scripted.
  • The store is Bashir's E2E store, not one of the four bug-hunt stores.
  • Benchmark identities get a fixed email code and simulated SMS, so real OTP delivery is out of scope.
  • One run, one browser. No concurrency or second-device behaviour exercised.
